# DeMaio Thesis Materials

This folder contains materials from my thesis.

**_DeMaio Defense_** is the slideshow I gave during my defense.

**_DeMaio_Thesis_Final_** is a PDF of my written thesis.

**_Figures_Final_** is a PowerPoint slideshow containing edited and unedited versions of most or all of the Figures I used in my thesis. Feel free to use these images in your work, as long as you give proper credit to the original creators.

**_Thesis.bib_** is the BibTex file I exported from Zotero containing all the references I used in my thesis.

If you would like to explore the Overleaf document in which I created my thesis, please contact Prof. Fichera for the link.
